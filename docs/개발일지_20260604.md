## 4. 트러블슈팅

| 문제 | 원인 | 해결 |
|---|---|---|
| git clone 경로 오류 | Bash에서 Windows 경로 역슬래시 처리 | PowerShell로 전환 |
| GitHub Pages 배포 안됨 | build_type이 'workflow'인데 Actions 파일 없음 | `deploy.yml` 워크플로 작성 |
| 로컬 ↔ 배포 화면 차이 | 브라우저 CDN 캐시 | Ctrl+Shift+R 강력 새로고침 |
| git 커밋 한글 메시지 오류 | PowerShell here-string 파싱 오류 | 영문 메시지로 변경 |
| 파비콘 Y 위치 어긋남 | 고정 좌표 사용 | `textbbox()`로 동적 중앙 계산 |
