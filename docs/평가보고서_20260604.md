## 2. 항목별 세부 평가

### 2-1. 기술 완성도 ★★★★☆

**잘된 점**
- 순수 HTML / CSS / JavaScript만으로 모던 인터랙션 구현 (외부 프레임워크 없음)
- Canvas API로 파티클 네트워크 직접 구현
- CSS Custom Property 기반 테마 시스템 — 런타임 교체 가능
- Python(Pillow)으로 OG 이미지 프로그래매틱 생성

**개선 여지**
- 프로젝트·경력·학력 섹션에 실제 콘텐츠 미입력 (placeholder 상태)
- Canvas 파티클 연산이 메인 스레드에서 실행 (OffscreenCanvas로 개선 가능)
- 이미지 최적화(WebP 변환, lazy loading) 미적용

---

### 2-2. 접근성 (WCAG 2.1) ★★★★☆

| 항목 | 결과 |
|---|---|
| 색상 대비비 (AA 4.5:1) | ✅ 준수 — 라이트 amber-700(4.6:1), 다크 yellow-300(12:1↑) |
| 포커스 링 | ✅ `:focus-visible` 적용 |
| 이미지 alt 텍스트 | ✅ 프로필 사진 alt 포함 |
| 버튼 aria-label | ✅ 다크토글·팔레트 FAB 적용 |
| 키보드 네비게이션 | ✅ Tab 키 이동 가능 |
| 시맨틱 HTML | ✅ `header` / `nav` / `main` / `section` / `footer` 구조 |
| 스크린리더 대응 | ⚠️ 일부 아이콘 버튼 추가 검토 필요 |

**개선 여지**
- 아이콘 전용 버튼에 `aria-label` 추가 검토 (contact-btn)
- `lang="ko"` 선언 완료, 다국어 전환 시 업데이트 필요

---

### 2-3. 사용자 경험 (UX) ★★★★☆

**긍정 요소**
- Hero 진입 애니메이션(fadeUp)으로 자연스러운 첫인상
- 타이핑 효과로 직책 정보 인터랙티브 노출
- 스크롤 연동 네비 활성화로 현재 위치 인지 쉬움
- 다크모드·테마 선택 저장(localStorage)으로 재방문 경험 개선
- 맨 위/아래 버튼으로 긴 페이지 탐색 편의
- 모바일 네비 가로 스크롤 (한 줄 유지)

**개선 여지**
- 실제 콘텐츠가 없어 현재는 데모 수준
- 페이지 로드 시 FontAwesome CDN 의존 (오프라인 불가)
- 네비바 글씨 크기가 다소 크게 느껴질 수 있음 (1.2rem)

---

### 2-4. 유지보수성 ★★★★★

**잘된 점**
- CSS Custom Property로 색상 한 곳에서 관리
- 테마 파일 분리 (`css/themes/*.css`) — 새 테마 추가 용이
- `generate_og.py` 스크립트 보존 — OG 이미지 재생성 가능
- 섹션별 `<!-- TODO -->` 주석으로 콘텐츠 입력 위치 명시
- 파일 구조가 단순하고 직관적

```
rest01/
├── index.html
├── css/
│   ├── style.css
│   └── themes/         ← 테마 추가 시 파일 하나만 생성
├── js/main.js
├── images/
├── docs/               ← 오늘 추가
└── generate_og.py
```

---

### 2-5. 배포 안정성 ★★★★★
